# Advanced SQL Sales Data Analysis

## Project Overview
This project uses MySQL to analyze sample sales data and identify revenue trends, top-performing products, customer purchasing patterns, and order status.

## Tools & Skills
- MySQL
- SQL Joins
- Aggregate Functions
- GROUP BY and ORDER BY
- Common Table Expressions (CTEs)
- Window Functions (RANK)
- Date Functions
- Data Analysis

## Database Tables
- **customers:** Customer details and cities
- **products:** Product names, categories, and prices
- **orders:** Order dates and order statuses
- **order_items:** Products and quantities in each order

## Analysis Performed
1. Total revenue from completed orders
2. Revenue by product category
3. Monthly revenue analysis
4. Customer-wise revenue and order counts
5. Top-selling products
6. Monthly revenue ranking using CTEs and window functions
7. Completed versus cancelled order analysis

## Key Findings
- Total completed-order revenue: ₹3,96,600
- Top category: Electronics — ₹3,00,000
- Highest-revenue month: June 2026 — ₹2,37,600
- Top customer by revenue: Aarav Sharma — ₹1,62,200
- Order status: 11 completed orders and 1 cancelled order

## Business Value
This project demonstrates how SQL can help businesses track revenue, compare product categories, identify valuable customers, monitor monthly performance, and analyze cancelled orders.

## Dataset Note
This is a sample dataset created for learning and portfolio purposes. The results are illustrative and do not represent a real company's sales.

## Skills Demonstrated
SQL querying, relational joins, data aggregation, customer analysis, sales reporting, CTEs, and window functions.
